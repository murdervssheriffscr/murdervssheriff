## 🛠️ Troubleshooting Common Issues

**❌ Script HUD doesn't appear after execution**
The executor may not have attached correctly to the Roblox process before you ran the script.
**Solution:** Close and reopen your executor, click **Attach** again and wait for the green status light before clicking **Execute** on the **Murder VS Sheriff Script**.

---

**❌ Silent Aim shots miss despite feature being enabled**
The `aim_bone` target may be set to a hitbox that gets occluded in your map geometry.
**Solution:** Open `...mvs_config.json` and change `aim_bone` from `"Head"` to `"Torso"` — the **Murder VS Sheriff Script Silent Aim** will have a larger valid target surface.

---

**❌ No Cooldown stops working after a map vote**
Map transitions trigger a partial game state reset that can deactivate some script flags.
**Solution:** The **Murder VS Sheriff Script No Cooldown** includes an auto-reapply toggle — enable `no_cooldown_persist = true` in your config file to reapply automatically after transitions.

---

**❌ Mobile executor crashes on inject**
Android memory management may be killing the executor process when Roblox is foregrounded.
**Solution:** Enable **Developer Options** on Android, set `Background Process Limit` to **No limit**, then reinject the **Roblox Murder VS Sheriff Script** with Roblox already in the foreground.

---

**❌ Config file not loading on startup**
The script looks for the config at a fixed relative path and fails silently if the file is missing.
**Solution:** Ensure `...mvs_config.json` is in the same folder as your executor working directory, typically `C:/Desktop/MurderVSSheriff/`. Rename the file exactly as expected — no spaces in the path.
